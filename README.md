# GSB Bugfix Task

## 题面

Go 粒子系统在透明排序后出现闪烁和穿插。粒子按发射顺序排序而不是按深度；同一深度的粒子排序不稳定；粒子排序和相机移动不同步；粒子缓冲每帧重建，旧数据残留；粒子数量超过上限后覆盖活跃粒子；粒子材质切换没有分批；粒子软粒子深度没有采样；粒子排序只算了中心点，没算包围盒；多线程发射粒子写同一缓冲；粒子死亡后槽位没有回收；粒子排序用了上一帧相机；粒子在半透明和加法混合间排序错误。

go test ./...
