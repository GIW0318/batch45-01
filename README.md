# GSB Bugfix Task

## 题面

io_uring 提交队列在高并发下出现请求串号，一个租户的读写落到了另一个租户的文件上。SQE 和 CQE 的 user_data 没有按租户编码；提交队列满时阻塞而不是返回；取消请求没有匹配原请求，取消错了对象；固定文件表在 fork 后共享，子进程能访问父进程文件；注册缓冲区在请求完成前被复用；超时请求没有清理，CQE 泄漏；链式请求中间失败，后续请求继续执行；同一 fd 并发注册两次，后注册覆盖；ring 设置没有限制 IORING_SETUP_SQPOLL 权限；请求完成顺序和提交顺序不一致时业务误判；ring 销毁时在途请求没有等待；租户配额没有按 ring 统计。
