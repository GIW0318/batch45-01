# GSB Bugfix Task

## 题面

Go 密钥管理服务在轮换时把旧密钥删早，线上出现一批解不开的密文。密钥版本没有和密文绑定，解密时总用最新版；轮换窗口内旧密钥立即删除；同一密钥并发轮换产生两个新版本；密钥用途没有区分加密和签名；HSM 会话断线后没有重连，密钥句柄失效；密钥导入没有校验材料长度；密钥销毁没有二次确认；备份密钥和主密钥存在同一故障域；密钥缓存没有过期时间；跨租户密钥 ID 冲突；轮换失败后没有回滚；重启后密钥版本表丢失。
