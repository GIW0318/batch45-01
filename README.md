# GSB Bugfix Task

## 题面

Go 合服角色迁移时，重名角色被覆盖，好友和公会关系错乱。迁移只检查了目标服角色名，没有检查大小写；同名角色直接覆盖；迁移过程不是原子的，失败后两边都有角色；好友关系只迁了一边；公会职位没有映射；邮件和背包附件丢失；成就进度没有合并；排行榜记录重复；迁移后角色 ID 变了但引用没更新；迁移队列没有幂等键；迁移期间禁止登录没有生效；回滚脚本没有测试。
