# GSB Bugfix Task

## 题面

Go 服务在内存里轮换数据库口令时，旧连接池仍用旧密码重连，导致故障切换后大面积失败。口令版本没有和连接绑定；轮换时旧口令立即从内存删除；连接池重连用的是创建时的 DSN；并发轮换产生两个新版本；口令缓存在多个副本间不一致；轮换失败后没有回滚；内存中的口令没有 mlock，可能被换出；日志里打印了 DSN；口令更新的传播有延迟；连接池没有优雅排空；新口令校验失败后仍切换；重启后加载了旧版本。

## 运行方式

```bash
go test ./...
```
