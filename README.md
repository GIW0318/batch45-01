# GSB Bugfix Task

## 题面

SBOM 证明服务在供应链审计时发现同一个构件有两份不同 SBOM。生成器按构建时间排序，后生成的覆盖先生成；SBOM 里的依赖版本用了范围而不是锁定版本；证明签名没有覆盖 SBOM 内容；同一 digest 的多个证明没有合并；材料列表漏了基础镜像；证明过期后仍被接受；并发构建产生两份证明，后写覆盖；证明里的构建参数包含密钥；SBOM 格式版本混用；依赖关系有环时递归爆栈；证明存储没有按租户隔离；审计查询返回了已撤销的证明。
