# GSB Bugfix Task

## 题面

Go 成就系统在合服后重复解锁并重复发奖。成就进度按角色而不是按账号；合服后两个角色进度合并时取最大值而不是累加；隐藏成就的条件文本出现在查询接口；同一成就并发解锁两次；奖励邮件在解锁事务外发送；进度回退没有拒绝；跨服成就计数没有同步；限时成就按本地时区判断；序列成就按字符串排序；团队成就把队友击杀记给队长；批量补发没有按时间排序；成就缓存没有失效。

## 运行方式

```bash
go test ./...
```
