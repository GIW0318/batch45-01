# GSB Bugfix Task

## 题面

Go 写的公会战匹配在高峰期把两个实力差三倍的公会排到一起。匹配池按报名时间排序，先到先配；公会战力用平均值而不是分位数；连败保护没有生效；同一公会被重复加入队列；匹配成功后没有从池里删除；跨服公会没有做延迟分组；匹配超时后直接放宽所有条件；小号公会可以被大号公会用来刷分；匹配结果没有记录种子，无法复盘；并发匹配同一对公会两次；赛季重置后匹配分没有衰减；拒绝匹配的惩罚没有生效。

## 运行方式

```bash
go test ./...
```
