# GSB Bugfix Task

## 题面

MACsec 密钥协商在 Go 实现里出现双 SAK 同时生效，链路两端各用一把。选举没有决出唯一密钥服务器就安装 SAK；优先级相同时没有按 SCI 决胜；并发选举两个线程都宣布自己胜出；SAK 安装不是原子替换，新旧同时可用；包序号按通道而不是按 SA 计数，换钥后旧计数干扰新计数；PN 用尽后没有强制重钥；ICV 校验失败被吞掉；控制帧重放没有检测；参与者列表不清理，掉线交换机一直参与选举；加密套件不匹配时降级；机密性偏移算错；重启后 CAK 丢失但 SAK 还在用。

## 运行方式

```
go test ./...
```
