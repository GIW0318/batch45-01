# GSB Bugfix Task

## 题面

Go 掉落保底在跨版本后失效，玩家连续开两百次都没出稀有。保底计数按账号而不是按卡池；十连和单抽共用计数但概率不同；保底触发后计数没有清零；跨版本继承时计数被重置；概率提升期结束后计数没有回退；同一卡池并发抽卡计数互相覆盖；保底奖励被普通掉落顶掉；伪随机种子按时间生成，无法复盘；保底计数没有持久化；多设备同时抽卡重复计数；保底阈值配置热更新后计数错位；邮件补发的保底奖励没有标记。
