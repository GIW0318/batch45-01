# GSB Bugfix Task

## 题面

Go 商店轮换在跨时区时提前刷新，玩家少买一天。刷新时间按本地时区；轮换任务重跑时重复扣限购次数；同一商品在多个分片有独立库存；限购按角色而不是账号；跨天购买没有重置；商品下架后已加购的还能买；轮换失败后旧商品没有保留；手动刷新没有审计；时区变更后刷新时间漂移；轮换锁没有过期时间；并发刷新产生两套商品；购买和刷新并发时读到半更新。

```bash
go test ./...
```
