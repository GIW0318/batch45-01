# GSB Bugfix Task

## 题面

Go 举报系统在封禁申诉期间把玩家永久封了。举报和封禁不在同一事务；同一举报被多个审核员重复处理；封禁时长按分钟累加，申诉期间仍生效；证据截图没有和举报绑定；误封后解封没有恢复道具；申诉超时自动驳回；同一玩家并发举报被合并成一条；封禁记录没有审计；跨服封禁没有同步；举报人信息泄露给被举报人；申诉期间仍能继续举报；解封后封禁计数没有清零。

## 运行方式

```bash
go test ./...
```
