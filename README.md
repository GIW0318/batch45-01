# GSB Bugfix Task

## 题面

Go 边界路由器收到上游泄漏路由后，把整张转发表带进了内网。入方向只按前缀长度过滤，没有校验 AS_PATH；私有 AS 被剥掉后仍接受；社区属性没有匹配白名单；最大前缀数没有限制；同一前缀的多个来源没有按优先级选；RPKI 验证失败的路线仍被安装；AS_SET 被当成正常路径；prepend 次数被清空后绕过；默认路由被无条件接受；路由抖动没有抑制；并发更新时旧路线覆盖新路线；重启后从空表开始。

## 运行方式

```bash
go test ./...
```
