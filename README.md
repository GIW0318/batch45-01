# GSB Bugfix Task

## 题面

内核文件访问控制模块在容器里出现漏判，挂载后的新路径不受规则约束。打开和 mmap 两条入口只拦了前者；挂载命名空间变化后规则没有重新绑定；rename 之后旧 inode 的规则还留着；inode 被回收再分配给新文件，规则误命中；规则表更新不是整体替换，读线程看到半张表；程序返回码约定混乱，允许和拒绝都可能返回 0；加载失败后系统回退到无规则；不同内核版本的 BTF 字段偏移不一致；通配规则把 /proc 也放进来；审计只记路径不记 inode；热更新时旧程序还在处理请求；容器挂载传播把新路径带进宿主。

## 运行方式

```bash
go test ./...
```
