# GSB Bugfix Task

## 题面

Go 背包事务在邮件附件领取时出现道具复制。领取邮件和写背包不在同一个事务；背包满时先删邮件再失败；同一附件并发领取两次；附件里的绑定道具被当成可交易；背包格子合并时数量溢出；邮件过期后附件没有退回；跨服领取没有加锁；道具堆叠上限没有校验；领取记录只在内存；背包扩容和领取并发；附件里的过期道具仍可领取；事务回滚没有恢复邮件状态。

## 运行方式

```bash
go test ./...
```
