# GSB Bugfix Task

## 题面

Go 编写的文件完整性监控在容器密集部署下漏报。inotify watch 数量达到上限后静默少挂目录；同一文件被多个容器挂载时只记录最后一个；事件队列溢出后丢事件没有补偿；rename 和 delete 事件没有关联，文件消失原因不明；递归监控没有处理新建子目录；符号链接指向监控目录外也跟随；文件哈希在事件到达后才算，期间内容已变；并发写导致哈希读到半更新；监控进程重启后基线没有重建；排除规则按字符串前缀，误排除了相似路径；事件时间戳用本地时间，跨时区排序错；容器删除后 watch 没有释放。

## 运行方式

```
go test ./...
```
