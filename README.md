# GSB Bugfix Task

## 题面

自研 QUIC 网关上线 0-RTT 后，重放和放大攻击一起冒出来。客户端换网络后重发 Early Data，服务端每次重新执行下单；同一 ticket 被两个连接同时使用，回退密钥被复用；0-RTT 数据在握手完成前就被业务消费，权限变更来不及生效；抗放大窗口只按包数算，不按字节算；Retry token 在集群节点间不共享，换节点就重放；连接迁移后路径校验没有重做，旧路径的包继续写进新连接；Early Data 被拒后没有通知客户端重发，业务静默丢单；ticket 加密密钥轮换时旧 ticket 仍能解；同一连接内 0-RTT 和 1-RTT 流号冲突；服务端把 0-RTT 包计入拥塞窗口，突发时误判；关闭连接后 ticket 还能用；集群重启后重放缓存全空。
