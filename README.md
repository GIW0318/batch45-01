# GSB Bugfix Task

## 题面

DNS-over-QUIC 代理上线后，同一查询在不同流上返回不同结果。流映射表按连接而不是按查询 ID 建键，两个并发查询互相覆盖；0-RTT 查询在握手完成前就转发上游，策略还没加载；流被重置后映射没有删除，后续查询落到旧流；上游响应的问题段和请求不一致也回写缓存；QUIC 连接迁移后流 ID 不变但路径变了，缓存键没带路径；EDNS 选项被截断，客户端拿到不完整应答；并发同名查询各自打上游，后完成的覆盖先完成；超时后流没有取消，上游继续占资源；DoQ 流优先级没有继承 DNS 优先级；连接关闭时在途查询没有返回错误；响应超过流控窗口被截断却标记成功；集群节点间不共享负缓存。
