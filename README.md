# GSB Bugfix Task

## 题面

Go 实现的设备直通管理器把同一块 GPU 分给了两个容器。设备分配表没有按 IOMMU 组加锁；容器退出后设备没有释放；同一 PCI 地址被重复注册，后注册覆盖；VFIO 组里的其他设备没有一起绑定；设备重置失败后继续分配；热插拔事件丢失，设备状态不同步；IOMMU 组共享时没有拒绝；设备权限按容器而不是按租户；并发分配同一设备两边都成功；设备直通后宿主机驱动没有解绑；容器迁移后旧节点设备没释放；重启后分配表丢失。

## 运行方式

```
go test ./...
```
