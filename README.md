# GSB Bugfix Task

## 题面

挂载命名空间传播在 Go 运行时里失控，容器卸载后宿主机还能看到挂载。挂载和卸载不是事务，任一步失败留下半套；shared 传播把容器挂载泄漏到宿主机；只读挂载能被 remount 成读写；并发创建容器时挂载表互相串；符号链接源路径解析到宿主机其他目录；卸载目标 busy 时错误被吞掉；容器退出后挂载没有清理；同一源目录两个容器选项互相污染；uid 映射和挂载属主不一致；挂载点超过上限没有报错；运行时重启后挂载状态没有恢复；中间失败后前面挂好的没有回滚。

## 运行方式

```bash
go test ./...
```
