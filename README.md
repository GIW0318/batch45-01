# GSB Bugfix Task

## 题面

Go 证书链构建器在交叉签名场景下选错了路径，把不受信任的中间证书当成了信任锚。链构建只按主题名匹配，不校验签名；同一主题多个中间证书时取了第一个；路径长度约束没有检查；名字约束没有应用到 SAN；策略约束被忽略；吊销检查只查叶证书；过期中间证书仍被使用；自签名证书被当成根；链里出现重复证书导致死循环；最大深度没有限制；AIAC 跳过中间证书；信任锚的指纹没有比对。

```
go test ./...
```
