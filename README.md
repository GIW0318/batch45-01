# GSB Bugfix Task

## 题面

Go 大世界服务器做分块加载后，玩家跨块时实体消失或复制。区块边界上的实体同时属于两个块，两边各跑一份 AI；实体迁移时旧块没有删除，新块又创建；跨块视野查询只查当前块；区块加载是异步的，玩家进入时地形还没好；实体 ID 在跨块后重新分配，任务引用失效；区块卸载时把还在战斗的实体一起删；边界寻路没有跨块；掉落物落在区块缝隙里丢失；多玩家同时触发同一区块加载，重复初始化；区块版本不一致时没有拒绝迁移；实体迁移不是原子的，崩溃后两边都没有；重启后区块与实体索引没有重建。

## 运行方式

```bash
go test ./...
```
