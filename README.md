# GSB Bugfix Task

## 题面

Go 任务链状态机在版本更新后把玩家卡在无法完成的任务上。任务前置只检查了第一步；分支选择后另一条分支的进度没有清理；任务物品在背包满时被吞；放弃任务后已消耗物品没有退回；跨地图任务的目标计数没有同步；任务链中途改版，旧任务 ID 不存在；自动交接任务在并发时重复接取；任务进度回退没有拒绝；日常任务和主线任务共用计数器；任务完成事件在事务外发出；离线玩家进度没有补算；任务奖励邮件在背包满时丢失。

## 运行方式

```bash
go test ./...
```
