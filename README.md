# GSB Bugfix Task

## 题面

容器运行时换用 Go 实现的 seccomp 编译器后，一部分容器启动就报非法系统调用。BPF 跳转偏移按指令条数算而不是按字节算，长程序越界；参数高低位没有拆分，64 位比较只比了低 32 位；同一 syscall 的多条规则没有按优先级排序，后面的覆盖前面的；默认动作在规则缺失时不是 kill；架构字段没有校验，x32 调用绕过；指针参数没有检查用户空间范围；规则里允许了 ptrace 和 bpf；过滤器长度超过内核限制没有报错；多线程程序里 seccomp 只对当前线程生效；规则继承标志没有设置，子进程逃逸；过滤器加载失败后回退到无过滤；热更新时旧过滤器没有原子替换。

## 运行方式

```bash
go test ./...
```
