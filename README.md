# GSB Bugfix Task

## 题面

Go 邮件系统批量发送补偿时，部分玩家收到两封，部分一封没有。批量任务重试时没有按玩家去重；邮件 ID 在重试时重新生成；发送成功但写回状态失败，任务又重跑；同一批邮件并发发送；收件人列表去重区分大小写；邮件附件在重试时被复制；离线玩家邮件被丢弃；邮件过期时间按发送时间算；批量任务分片后没有记录进度；队列积压时新邮件覆盖旧邮件；跨服邮件没有路由；发送失败没有死信队列。

go test ./...
