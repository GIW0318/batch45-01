# GSB Bugfix Task

## 题面

nftables 规则同步器在滚动更新时出现短暂全放行。表替换不是原子的，先删后加之间没有规则；set 元素更新时整表重建，正在匹配的包看到空集；规则顺序按 map 遍历生成，顺序不稳定；注释字段没有转义，特殊字符截断规则；超时 set 的 timeout 单位混用秒和毫秒；计数器重置导致监控误判；同名 chain 在多个表里冲突；规则引用不存在的 set 时静默跳过；批量提交失败后没有回滚；IPv6 规则被写到 IPv4 表；规则里允许了所有 icmp；同步器重启后从空表开始。
