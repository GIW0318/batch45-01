# GSB Bugfix Task

## 题面

制品签名门禁上线后，未签名的镜像仍能进入生产。验签只确认存在一张签名，没有核对签发者；信任根过期后继续沿用旧根；清单摘要和实际拉取对象不是同一个；多架构清单只验了当前架构；证明文件和镜像没有绑定；离线缓存没有有效期；验签失败后回退到放行；并发拉取同一镜像时缓存互相覆盖；签名里的 critical 字段被忽略；签发者公钥轮换后旧签名仍可用；门禁重启后信任根丢失；仓库返回 404 时被当成通过。
