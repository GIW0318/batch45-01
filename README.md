# GSB Bugfix Task

## 题面

Go 写的类 WireGuard 隧道在弱网下频繁掉线，抓包看到握手包序号倒退。握手发起方的临时公钥每次重传都重新生成，响应方按新会话处理，旧的半开状态泄漏；重放窗口按消息类型分开存，切换密钥后旧计数干扰新计数；cookie 回复没有和源地址绑定，换端口也能拿到；握手超时后没有清理半开状态，内存一直涨；双方同时发起握手时产生两套会话，数据面各走一条；密钥轮换没有等旧包排空，在途包被丢；keepalive 不区分方向，回包把空闲计时重置；重传次数没有上限，坏链路一直重试；握手消息的 MAC 计算漏了接收方索引；同一公钥被两个 peer 同时注册，后注册的覆盖前者；隧道删除后定时器还在跑；重启后会话与重放窗口没有一起恢复。

## 运行方式

```bash
go test ./...
```
