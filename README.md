# GSB Bugfix Task

## 题面

Go 批处理平台在跑抓取任务时把整机文件句柄耗尽，sshd 和监控一起报错。句柄配额按进程而不是按租户；打开文件后异常路径没有 defer 关闭；连接池没有上限，空闲连接一直占句柄；日志文件每次请求重新打开；临时文件删除后句柄没关；并发任务各自翻倍打开同一文件；句柄泄漏检测只看总数，不看租户；达到软限制后没有拒绝新任务；子进程继承了大量句柄；目录遍历没有关闭 Dir；超时取消后后台 goroutine 还在读；重启后泄漏句柄没有清理。

## 运行方式

```
go test ./...
```
