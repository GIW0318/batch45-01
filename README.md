# GSB Bugfix Task

## 题面

Kubernetes 准入控制器在 Go 里做镜像策略，带特权的 Pod 还是被放行。控制器只匹配 Pod，没有匹配 Deployment 模板；失败策略设为忽略；规则里的 API 组写成通配；副作用标成无但实际有；等效匹配导致更新绕过；镜像摘要没有固定，标签被覆盖；特权字段只查了普通容器，漏了初始化容器；宿主路径挂载没有限制；能力只看了新增没看丢弃；命名空间选择器排除了系统命名空间；请求超时后放行；证书轮换后旧连接仍用旧证书。

## 运行方式

```bash
go test ./...
```
