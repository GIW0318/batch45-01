# GSB Bugfix Task

## 题面

gRPC 服务改用 mTLS 后，吊销的客户端证书还能调用管理接口。拦截器只验证书链，不查吊销状态；OCSP 超时按通过处理；证书 SAN 和租户映射只取第一个，多个 SAN 时串租户；会话恢复后沿用了旧证书身份；同一证书被并发映射到两个租户，后写覆盖；中间证书缺失也判有效；证书过期后有隐式宽限期；gRPC 连接复用时不重新校验证书；网关注入的客户端标识头被直接信任；吊销列表刷新失败时继续用旧表；证书序列号重复没有告警；集群节点各自缓存吊销状态，结果不一致。
