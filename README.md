# GSB Bugfix Task

## 题面

Go 的 UI 文本层在中文长段落里开始缺字，放大后边缘发虚。每个新字形都重新生成位图，同字号重复生成；缓存槽满了就把正在显示的字形顶掉；字形位图的行宽没有按 4 字节对齐，采样偏移；不同字重的同一字符共用一个槽；连字和组合字符被拆成多个槽；回退字体链按系统顺序而不是按语言；缓存更新和渲染线程之间没有栅栏；字形度量按包围盒而不是基线；缓存尺寸变化后旧坐标全部失效；多线程同时写同一个槽；换行只按字符数不按实际宽度；彩色 emoji 被当成单色位图。

## 运行方式

go test ./...
