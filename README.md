# GSB Bugfix Task

## 题面

Go 审计日志管道在高峰期丢事件，安全审计无法还原操作链。日志先写内存队列，队列满直接丢；多 goroutine 写同一文件，行交错；事件序号在重启后归零，前后无法排序；敏感字段没有脱敏，token 进了日志；日志轮转时正在写的文件被 rename，后续写到旧 inode；审计事件和业务事务不在同一提交里，业务成功日志丢失；远程 syslog 断线后没有本地缓冲；同一操作产生重复事件；时间戳只用本地时间；日志文件权限过宽；磁盘满时静默失败；查询接口返回了未脱敏内容。

## 运行方式

```
go test ./...
```
