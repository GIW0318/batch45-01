# GSB Bugfix Task

## 题面

Go 阴影图集在场景切换后出现相邻页串影。页分配只按大小排序，没有对齐；同一盏灯重复分配页；页释放后没有清空深度；图集更新和采样之间没有屏障；级联阴影的页没有按距离分配；动态物体和静态物体共用页但没有分帧更新；阴影页被邻居采样到，边缘出现漏光；页表溢出后覆盖正在使用的页；光源删除后页没有回收；图集尺寸变化后 UV 没有重算；多线程分配同一页；图集重建时旧页还在渲染。

## 运行方式

```bash
go test ./...
```
