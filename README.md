# GSB Bugfix Task

## 题面

Go 实现的文件配额执行器在构建集群上出现跨项目超卖。配额按用户统计而不是按项目编号，跨项目互相占用；硬限制只查数据块不查 inode；宽限期从项目创建时间算而不是首次超限；多个进程并发写，各自看到剩余额度都够，合计超卖；删除文件后配额延迟回收；父项目限制没有向下取最小；硬链接和符号链接被重复计数；rename 和 truncate 绕过配额检查；超限返回空间不足但部分数据已落盘；快照和备份目录没计入配额；修改配额对已打开句柄不生效；稀疏文件按表观大小计算。

## 运行方式

```
go test ./...
```
