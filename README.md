# GSB Bugfix Task

## 题面

Go 副本锁 CD 在跨服后错乱，玩家一周能拿两次首通奖励。锁 CD 只按角色 ID，没有按副本难度和赛季；跨服后角色 ID 映射不一致；锁记录只存在内存，重启丢失；首通奖励和普通奖励共用同一个标记；队伍里有人有 CD 有人没有，进本时没有校验；跳车后 CD 没有保留；副本重置时间按本地时区；同一角色并发进两个队，两边都创建副本；锁 CD 的过期时间没有持久化；GM 重置没有审计；跨服转移后 CD 没有跟着走；首通奖励领取不是原子的。

## 运行方式

```bash
go test ./...
```
