# GSB Bugfix Task

## 题面

Go 地形 LOD 在相机移动时出现裂缝和跳变。相邻块的 LOD 级别没有对齐，接缝处高度不一致；LOD 切换没有滞回，边界来回跳；裙边高度不够，远处看到空洞；LOD 选择只看距离，没有看屏幕误差；地形法线在 LOD 之间没有插值；高度图采样在块边界越界；LOD 网格索引没有按块偏移；多线程生成网格时共享顶点缓冲；LOD 切换时阴影没有同步；地形纹理 UV 在 LOD 之间不连续；块卸载后 GPU 缓冲没有释放；相机快速移动时 LOD 更新排队。

go test ./...
