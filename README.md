# GSB Bugfix Task

## 题面

Go 实现的系统调用过滤在热更新时出现短暂无保护窗口。新规则编译期间旧规则被卸载；规则替换不是原子指针交换，goroutine 读到半初始化结构；更新失败的规则回滚不完整；多个更新请求并发，后到覆盖先到；规则版本没有递增，审计无法对应；更新时正在执行的 syscall 被中断；规则里的路径依赖挂载点，热更新后失效；过滤器句柄泄漏；更新过程阻塞业务线程；新规则比旧规则宽时没有二次确认；更新日志缺失；重启后加载了旧版本规则。

## 运行方式

```
go test ./...
```
