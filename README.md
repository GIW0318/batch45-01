# GSB Bugfix Task

## 题面

Go 写的帧同步战斗服在回放时出现不同步，同一帧的输入在不同客户端算出不同结果。输入包按到达时间排序而不是按帧号和玩家序号；同一玩家一帧内多次输入只保留最后一个；丢包后没有等待补发就推进帧；浮点运算在不同架构上结果不一致；随机数种子按本地时间生成；技能冷却用真实时间而不是逻辑帧；实体遍历顺序依赖 map 迭代；回放文件没有记录帧号；断线重连后从当前帧开始而不是从快照恢复；输入缓冲区满了直接覆盖旧输入；校验和只算最终状态不算中间帧；服务器和客户端用不同的定点精度。

## 运行方式

```bash
go test ./...
```
