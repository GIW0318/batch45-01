# GSB Bugfix Task

## 题面

Go 贴花系统在大量爆炸后出现贴花错位和闪烁。贴花投影矩阵没有随物体移动更新；同一帧内贴花排序按 ID 而不是深度；贴花图集页分配后没有释放；贴花跨多个网格时只投影到一个；贴花法线混合方向反了；贴花透明排序和粒子混在一起；贴花距离剔除用了包围盒中心；贴花数量超过上限后覆盖最旧的；贴花在移动平台上没有跟随；贴花图集更新时 UV 没有重算；多线程写同一贴花槽；贴花删除后深度缓冲没有恢复。

## 运行方式

```bash
go test ./...
```
