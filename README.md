# GSB Bugfix Task

## 题面

Go 服务器权威移动上线后，客户端预测和服务器校正打架，玩家看到角色来回拉扯。客户端预测没有带输入序号；服务器校正直接瞬移，没有平滑；同一输入被服务器执行两次；移动速度受帧率影响；碰撞检测只在服务器做，客户端穿墙后才被拉回；延迟补偿用当前时间而不是输入时间；丢包后客户端继续预测，偏差越来越大；服务器 tick 和客户端 tick 不同步；瞬移阈值太小，正常网络也触发校正；垂直移动没有单独处理；载具上的玩家位置没有跟随；回滚后动画状态没有重置。

## 运行方式

```bash
go test ./...
```
