# GSB Bugfix Task

## 题面

Go 音频混音器在同屏特效多时出现爆音和语音被吞。混音前没有做限幅；语音通道被音效通道挤占；Voice stealing 按最旧而不是最轻；同一帧内多个音效同时开始，相位叠加；混音缓冲没有清零；采样率不一致的通道直接相加；3D 声像没有按距离衰减；混音线程和资源加载线程竞争；语音优先级没有动态调整；音频设备回调里分配内存；混音超出预算后丢帧；暂停后恢复播放位置错乱。
