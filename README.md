# GSB Bugfix Task

## 题面

内部 TOTP 服务在时钟漂移时出现大面积验证失败，同时旧验证码还能复用。时间步只按服务器本地时间算，没有容差窗口；同一验证码在窗口内可重复提交；验证码用普通字符串比较，存在时序侧信道；密钥轮换后旧密钥立即删除，在途验证全失败；同一用户并发验证两次，两边都成功；漂移超过一个步长没有告警；备份码没有一次性标记；TOTP 密钥明文存库；算法从 SHA1 升到 SHA256 时没有版本字段；验证失败次数没有限速；跨租户的密钥 ID 冲突；重启后已用验证码缓存清零。
