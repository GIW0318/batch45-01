# GSB Bugfix Task

## 题面

Go 实现的只读镜像校验在启用 fs-verity 后仍然放行了被替换的二进制。verity 描述符没有和文件内容一起校验；签名只覆盖了 merkle 根，没有覆盖描述符版本；文件被替换后 inode 没变，缓存仍判有效；多架构镜像只校验了当前架构；校验失败后回退到普通哈希；并发读取时文件被修改，校验和读取不一致；verity 未启用时静默跳过；签名公钥轮换后旧签名仍接受；校验缓存按路径而不是按 inode；镜像层解压后没有重新校验；校验器重启后缓存丢失；远程镜像的 verity 元数据没有一起拉取。

## 运行方式

```
go test ./...
```
